# Excel Data Analytics Portfolio

## Project Overview
This repository contains a collection of Excel projects designed to solve real-world data challenges. The work ranges from fundamental data cleaning assignments to a comprehensive Capstone Project involving multi-table relational data and interactive dashboards.

---

## 1. Excel Capstone Project: Sports Retail Analysis
This project analyzes three years of sports-related sales data (2023-2025) for a USA-based company.

### Key Components:
* **Data Modeling:** Organization of data into `Customer_Dim`, `Product_Dim`, `Store_Dim`, and `Sales_Fact` tables.
* **Data Cleaning:** Resolving missing loyalty levels, product costs, and stock details across multiple sheets.
* **Regional Analysis:** Identified the **North Region** as the top performer in online sports product sales.
* **Strategic Insights:** Analysis of the **West Region** revealed high demand but limited physical store presence, leading to a recommendation for opening new locations to maximize growth.
* **Visualization:** Summarization of sales by category (Beauty, Clothing, Electronics, Home, Sports) and payment types (COD, Credit Card, PayPal).

## 2. Assignment 2: Data Pre-processing & Formatting
A focused exercise in data engineering and quality assurance.

### Objectives & Techniques:
* **Missing Value Imputation:** Grouping products to calculate average prices for filling gaps.
* **Data Standardization:** Standardizing text formats in "Product Name" and fixing typos in "Category" (e.g., correcting "Electroni" to "Electronics").
* **Feature Engineering:** Splitting "Product ID" into "Manufacturing Date" and "Country Code"; merging "Brand Name" and "Product Name" into a single "Product Brand" field.
* **Conditional Formatting:** Using data bars and color scales for price analysis and custom rules to highlight specific categories.
